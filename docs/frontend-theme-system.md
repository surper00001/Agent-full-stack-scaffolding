# 前端主题系统

## 概览

两套企业级配色主题，远离 AI 蓝紫调，通过 CSS 自定义属性 + `data-theme` 属性切换。

## 主题一：Emerald 深翡翠

专业、沉稳、可信赖 — 适合金融/企业场景。

- 主色：翡翠绿 `hsl(162, 65%, 28%)`
- 底色：暖灰绿调
- 暗色模式：深绿黑底 + 亮翡翠主色

## 主题二：Warm Amber 暖琥珀

温暖、亲和、创造力 — 适合设计/创意工具场景。

- 主色：琥珀金 `hsl(32, 75%, 34%)`
- 底色：暖奶油调
- 暗色模式：深咖啡底 + 亮琥珀主色

## 技术实现

- HTML 根元素：`data-theme="emerald|amber"` 控制色系
- HTML 类名：`.dark` 控制明暗模式（沿用 shadcn/ui 方案）
- 组合：4 种模式（emerald-light, emerald-dark, amber-light, amber-dark）
- 存储：`localStorage.colorTheme`
- 过渡：核心属性 200ms color/background/border 过渡

## 切换组件

Header 区域提供色系切换按钮（两个小色块并排），点击在 Emerald / Amber 之间切换。
明暗切换保持独立。
